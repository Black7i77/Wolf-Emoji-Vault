# Wolf Emoji Vault v1.1 Deluxe

Offline emoji Unicode steganography demo. Open `index.html` in Firefox or another modern browser.

Features: categorized and searchable emoji palette, custom emoji, encode/decode, copy, live integrity check, opt-in browser-local history (last 20), deletion and JSON export.

**Important:** This is NOT encryption, authentication or a security bypass. Text is recoverable by anyone who knows the encoding. Platforms can remove zero-width characters. History is stored in browser `localStorage` as plain text and may not persist for `file://` pages in all browsers. No remote network calls.
